Keep the comparison fair

  1. Keep the full black square and white margin visible. Adjust browser zoom so the black square has the same physical width for each marker.
  2. Use the same lighting, phone, distance and angle. Start front-on, then slowly tilt.
  3. Switch to Show test cube to inspect trembling without the ghost's floating animation.
  4. Hold each marker in view for 20 seconds. Compare the Losses counter; it counts lost detections, not pose jitter.
  5. Hide and reveal the marker to test recovery. These intentional losses count too.

No smoothing has been added: all three tests use the same rendering settings. Counters reset when you leave or reload the test.
